`Cargo.toml` (the seven `shm-*` workspace dependencies), `Cargo.lock` (their seven `source`

## Why

This is the later pin move I51 expected. The programs that use both Orion and the device library
are moving to the device library's `next` at `7b4fdb25`. Orion moves its pins there so that all
of them land on one pair of revs.

## Built

- **Cargo.toml.** The seven `shm-*` workspace dependencies come from the `.git` URL, at
  `7b4fdb255826fe2c00caadd5716e807c31364b12`. `0d37cc55` is an ancestor of that rev.
- **The lockfiles.** Only the `source` lines change. No package is added, removed or moved to
  another version.
- **No byte Orion builds changes.**
  - Between `0d37cc55` and `7b4fdb25`, the device library's `shm` directory changes in only two
    places: `shm/README.md` and `shm/measure/src/sched.rs`. The `sched.rs` change sets the core
    limit in a child that is meant to die.
  - `shm-measure` is only a dev-dependency of the `shm-*` crates. It is not in any of Orion's
    lockfiles.
  - The device library's workspace `Cargo.toml` is byte for byte the same at both revs.

## Proof

- **The device library's checkers**, from `7b4fdb25`, on `Cargo.lock`:

  | | its pin check (at `7b4fdb25`) | its one-source check |
  |---|---|---|
  | Before | fail: 7 of 7 crates not at the pin | pass: one copy of each of 7 |
  | After | pass: all 7 at the pin | pass |

  Both example lockfiles also pass both checks: their one `shm-*` crate is at the pin.
- **The sources.** `git diff --stat 0d37cc55 7b4fdb25 -- shm/` lists only the two files above.
- **`cargo metadata --locked`** resolves the new lock.
- **The landing gate passed.**

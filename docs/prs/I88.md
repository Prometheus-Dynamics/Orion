## Why

The device library's `next` is at `6c8568d0`. The programs that use both Orion and the device
library move to it for the next image, and Orion moves its pins there so that all of them land
on one pair of revs.

## Size

The first gate was red at size: `orion` for a board was 5,510,072 bytes, 72 over its limit of
5,510,000, and 848 over what I86 measured (5,509,224). `orion-recovery` for a board moved too,
by 960, to 2,763,440 (limit 2,770,000, unchanged).

No source changed. The rev is part of the seven crates' identity, so their symbols are named
differently, and the one whole-program link came out a few hundred bytes different. That is
the likely cause; it was not taken apart further than "the same sources, another rev".

**The limit for `orion` on a board is raised by 40,000, to 5,550,000.** This is the raise for
the whole clock row (I80 to I84), brought forward because the pin move could not land without
room. I82 to I84 add no raise of their own.

- **The reason.** The clock row is real code on the board: a computer's clock taken and named,
  the clock's state said three ways, the hardware clock as a floor, what the kernel is told,
  and still to come the lease shift on a clock step, the `gateway` and `nt4` sources, and the
  shared time base. I80 and I81 used all the margin there was.
- **Cut first.** I81's re-announce lost its task and two channels: 8,600 bytes.
- **What the bytes so far are.** I81 over I80, +13,896 on the board. By crate, measured on
  this machine's build of the same binary (text, +9,920):

  | Where | Bytes |
  | --- | --- |
  | `orion-comm-app` | +4,772 |
  | `orion-time` | +2,255 |
  | `std` | +1,778 |
  | `orion-mdns` | +856 |
  | `orion`, `orion-ctl` | +114 |
  | `orion-hello` | +83 |

  I86 added 64 bytes, and this pin move 848 with no source changed.
- **What the figure is.** A ratchet against growth nobody chose, not the room there is: the
  slot the file ships in has room to spare.
- **Margin from now on.** A limit is kept at least 4,000 bytes above what was last measured.
  I86 left 776, and a change of no source tripped it.

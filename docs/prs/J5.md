## Changes

`scripts/gate.sh`

## Build

Board images build `orion` and `orion-recovery` `--locked --offline`, from crates vendored from
`Cargo.lock` alone. A lockfile that no longer matches the manifests would build here and fail
there. The gate's first step is now `cargo metadata --locked`, which fails if the lockfile would
have to change.

## Proof

A dependency added to a manifest with the lockfile left as it was: the step fails with "cannot
update the lock file … because --locked was passed".

## Built

As above.

## Proved by

The case above, by hand; the gate passes on the tree as committed.

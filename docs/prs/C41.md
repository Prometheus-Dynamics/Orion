# C41: Where the bytes went since I6, what was cut, and limits held tight

**Status:** done

**Group:** C. Comm core

**Wave:** 18

**Needs:** C40

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`crates/comm/server/src/retry.rs`, `crates/comm/comm-app/src/ways.rs`,
`crates/comm/comm-app/src/lib.rs`, `scripts/size-gate.sh`, `docs/comm.md`, `TODO.md`.

## Build

Find the reason for the growth of `orion` since I6, by crate and by symbol. Cut what is fat for
no benefit. Set each limit to what is measured and a small margin, not a tenth. That includes
correcting C39, which raised the host limit by a tenth (660 KB) for a 4 KB overrun.

## Built

### How it was measured

Built with `cargo bloat`, profile `service` as it ships but with symbols kept
(`CARGO_PROFILE_SERVICE_STRIP=false`). I6 is `1fa0ca7`; J11 is `25e9125`; HEAD is C40 `d24d90e`.
The sizes below are stripped with `strip --strip-all`. The gate's own strip comes out about
10 KB smaller, and the limits are set from the gate's numbers.

| Build | `.text` | Stripped |
| --- | ---: | ---: |
| I6 | 3,788.8 KiB | 5,943,960 |
| J11 | 4,313,895 B | 6,545,784 |
| C40 | 4,354,087 B | 6,601,168 |
| C40 after the cut (this PR) | 4,331,559 B | 6,570,456 |

I6 to C40: +657,208 bytes stripped (+11.1%), `.text` +512 KiB (+13.5%).

So the growth is features: about 130 KiB in crates that did not exist in this binary at I6, and
the rest in node logic and the comm core doing more. No one symbol is large for what it does.
`Carriers::accept` is the one dispatch that keeps the server to a single instantiation, so its
size is the carriers' own accept code, not copies of it.

### Fat for no benefit, cut

C40 had cost 55,384 bytes stripped (J11 → C40). Two parts of it were copies:

- `now_or_later` was generic over each way in's start future, so each future was compiled into
  both the first try and the retry task. It now boxes the start and its result
  (`Box<dyn Any>`), and the trying (`erased`) is compiled once.
- `open_retrying` carried its warning, its info line and its waiting in every instance (tcp, ws
  and the comm core). They are now in one non-generic `Tries`.

Saved: **30,712 bytes**. What C40 costs now is 24,672 bytes. Most of what is left moved out of
`CommCore::start` (−16.4 KiB) into the two boxed starts (+20.4 KiB), and the retry task and the
WebSocket's opening are about 8 KiB.

existing limit that was already tighter is kept.

## Proved by

- The sizes above, from the builds named.
- After the cut: the C40 tests (`ways`, `comm`, `recovery`, `opening`, tcp `listen`, the retry
  unit test) pass. The mutations on the parts that moved are still caught: the later guard
  both ways, the task keeping its server, the NT4 error kind, and `may_clear`'s kinds.
- The gate, with the new limits.

## Different from the brief

- The I6 symbol diff names functions as they are now. Code that moved module (`Carriers` from
  `lib.rs` to `carriers.rs`) shows as one removed and one added symbol, and is read as the
  difference of the two.

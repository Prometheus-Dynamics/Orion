## To do

- **The listener log line.** Each network listener logs at info when it opens, at start and
  each time again after its interface went: `network: eth0: open on 0.0.0.0:9200`.
- **`orion/state` network lines.** A line for each listener, made when the file is:
  `network: eth0 open on …`, `network: usb0 waiting (<why>)`.
- **ROOT-SETTING-REFUSES-ROOT.** Each `files.root.<name>` line is read on its own.
  - A line that is not a root is refused alone, logged once, and put in the hello fact
    `files` as `root <name> refused: <why>`. The rest are offered.
  - `orion file fetch` from a refused root says why, not only "not found".
- **Security off, a shell over the network.** A test: a tool with no key, over `orion+tcp`,
  opens a shell on a terminal, runs a command and gets its exit code.
- **The `mut` warning** in `comm-app` `settings.rs`, seen in every build without `shell`.

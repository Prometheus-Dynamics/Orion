# I59: A hello fact may be up to 1024 bytes, and one that is longer is logged once

**Status:** done

**Group:** I. Finish

**Wave:** 19

**Needs:** I58

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`crates/comm/hello` (`src/lib.rs`, `tests/hello.rs`, `Cargo.toml`), `Cargo.lock` (the two new
dependency edges of `orion-hello`), `docs/comm.md`, `docs/lock.md`, `TODO.md`.

## Why

The hello left out every fact value over 256 bytes without a word. The device library allows
1024 bytes for each fact value, and its `offers` fact, with 19 contracts, is 302 bytes. So the
board's hello carried no `offers`, and a tool that needs it refused the board.

## Built

- **`MAX_FACT_BYTES` is 1024.** A fact value of up to 1024 bytes is carried in the signed
  document. A longer one is left out, as before. `recovery_why` is cut to the same 1024.
- **A fact that is left out is logged.** The first time a fact is too long, a `warn` line names
  it, its size and the limit: `hello.<fact>: <n> bytes is over the 1024 bytes a fact may be:
  left out of the hello`. The line is written once for each fact (its topic and epoch), however
  often the hello is asked for.
- **Nothing on the wire changes.** The limit is how the hello behaves, not a field. Interface
  level 6.
- **No limit on the whole document.** None is added here.

## Proof

- **New test:** `a_fact_of_up_to_the_limit_is_carried_and_a_longer_one_is_left_out_and_logged_once`.
  - A fact of 1024 bytes and a 302-byte text `offers` are both in the signed document.
  - A fact of 1025 bytes is not.
  - The hello is asked for twice, and the log has the one `warn` line.
- **The existing tests** now use `MAX_FACT_BYTES + 1` for the fact that is too long, and
  `MAX_FACT_BYTES` two-byte characters for the reason that is cut.
- **Mutants**, each run 3 times, fail every time:
  - the limit back at 256;
  - the `warn` made a `trace`;
  - a `warn` on every ask.
- **Before the change**, a probe at `19be7e04` publishing a 302-byte text `offers` found it
  missing: the document had only a 256-byte fact and `state`.
- **The landing gate passed.**

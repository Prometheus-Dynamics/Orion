# I122: measure-change.sh measures more than a comment

**Status:** done

**Group:** I. Finish

**Wave:** 19

**Needs:** I121

Read `AGENTS.md` and `docs/design.md` first.

## Why

I121 keys tests by what their binaries run. That has to be measured across the gate, and not
only for a comment: a change to code that never runs, and a change to code that does, behave
differently.

## Changes

- **`MEASURE_CHANGE`** in `scripts/measure-change.sh` picks the change. Each kind is made
  different on every run, so each run is a change:
  - `comment`, the default: a comment line appended, as before;
  - `unused-fn`: a `pub fn` that nothing calls, appended;
  - `used=TEXT`: TEXT, a string in FILE, made longer. For example, `used=malformed data` in
    `orion-types`' `error.rs`.

  An unknown kind, or TEXT that is not in FILE, is refused before any run. Each run's line names
  its kind.

## Proved by

Each kind was applied to scratch copies of `lib.rs` and `error.rs`, and each diff shows exactly
the intended change. The function name is lower case, so `non_snake_case` does not fire.

# I115: A script changed runs again only the tests that may read it

**Status:** done

**Group:** I. Finish

**Wave:** 19

**Needs:** I114

Read `AGENTS.md` and `docs/design.md` first.

## Why

The one-minute rule (2026-11-24). Every package's tests carried one digest of every file
outside the crates (I110). A change to any script, page or example ran all 95 packages' tests
again, though most never read a file outside their crates.

## Changes

- **Only a package whose sources may reach outside the crates carries that digest**
  (`scripts/lane-reuse.py`, `reaches_outside`). That is a Rust source of the package that:
  - names a path outside the crates (a top-level entry other than `crates/`, or `..`);
  - walks up (`.parent()`);
  - finds its own binary or the target (`current_exe`, `CARGO_TARGET_TMPDIR`);
  - or runs cargo.

  The rule is broad on purpose: a package flagged wrongly only runs its tests more often. 27
  of 95 packages are flagged. What a package reads when compiled stays held by its `.d` files
  (`depinfo`). The rule is a port of another project's measured design, which adopted the
  same lane keys.
- **`scripts/measure-change.sh FILE RUNS TARGET_DIR LOG_DIR`** runs the whole gate RUNS times,
  each after a fresh comment in FILE, and prints each run, the median and the slowest. It runs
  at the one nice level.

## Proved by

- **The keys' self-test** has two new cases. A page changed moves the key of the browser
  tests, which load it, and leaves `orion-ctl`'s alone. With `reaches_outside` always false,
  3 of 3 failed, naming the first case. With it always true, 3 of 3 failed, naming the second.

## Measured

Before it, on I114 at nice 10: a leaf change's gate took a median 43.4 s and at slowest
55.6 s, over 5 runs at load 105 to 134. A core change's took 249.2 s and 1,100 CPU-s, at load
124 to 109.

The size gate was tried with one target directory per target, its builds in turn, so the
crates they share are built once. That was not kept. On two core changes, order alternated,
load 74 to 96, its CPU time went from 448 and 337 CPU-s to 383 and 380, and its wall time from
173 and 100 s to 193 and 213 s. The cost is in the fat-LTO links, not the shared crates.

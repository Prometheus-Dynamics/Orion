## Why

The first part of the clock row. A board has no battery on its clock, so after a power cut it
starts with no real time. The board could already take the time from an operator who offered
it (`TimeOffer`, `TimeTurn`, then the board's `TimeRequest` answered by `TimeReply`), but no
client sent the offer or answered the board, and `orion.time` said only `operator`, not whose
clock it took.

## Built

- **`Orion::offer_time(stratum)`** sends the offer and gives how often the board will ask.
  From then on the session answers the board's `TimeRequest` for the wall clock whenever it is
  pumped, by any call or `pump(wait)`, for as long as the session lasts. `times_asked()` counts
  the requests answered.
- **`orion node offer-time [--stratum N] [--for MS]`** offers this computer's clock and answers
  until stopped, or for `--for`, saying each time it is asked. The stratum is 2 unless given,
  and must be 1 to 15.
- **Whose clock it took.** `orion.time`'s `source` is `operator <name>` (the name from its
  hello), with `(key <first 8 hex>…)` for an operator that proved its key. An offered time is
  held to the build's date, as every source's is.
- **The grant, said.** With security on, an offer needs an operator granted `clock.set`. An
  operator without it is refused `denied: needs the grant clock.set`. This comes from a general
  change: every refusal for want of a grant now names the grant (`read`, `*` for a write,
  `login or shell:ACCOUNT`, or the action's name). The code is still `denied`. A program on the
  board is refused `denied`. With security off any session's offer is taken, as off means
  everywhere; `docs/comm.md` now says so.
- `scripts/size-gate.sh`: recovery is carried by no image, so its limit only keeps a binary
  nothing ships lean (the image side's answer).

## Tests

- `orion-test-board` (`time::`):
  - `with_security_off_any_programs_clock_is_taken_and_named`: a program offers; the board takes
    it, and `orion.time` names `operator bench-pc`.
  - `a_board_that_takes_no_time_from_operators_says_so`: refused `unsupported`.
  - `with_security_on_only_an_operator_granted_clock_set_gives_the_time`: an operator without the
    grant is told `needs the grant clock.set`; one with it is taken and named with its key.
- `orion-time` `an_operator_with_the_grant_gives_the_board_its_clock`: the source names the
  operator and its key.
- `orion-ctl` `verbs::node_show_peers_and_time`: `node offer-time` on a board that takes no
  offers says `not supported`; `--stratum 16` is refused before any board is asked.

## Build

- The signed session from dev on the new wire. One connection each way per peer.
- Always push.
- Access paths never back off.

Built with one change from dev's signed session. Dev signed every request and signed every answer
back. A session here carries streams as well as requests, so each side proves its identity key
once, in a handshake over fresh values and an ephemeral key exchange, and every frame after
carries a MAC under the session's key. What crosses the wire has the same guarantee (it cannot be
forged, changed, dropped or reordered) for a MAC per frame instead of a signature. It is not
encrypted, as on dev.

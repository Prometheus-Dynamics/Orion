push waits for on CI. CI's main runner has 4 cores, and both steps are CPU-bound, so beside
each other they only shared them.

`gate (main)` on CI:

| Run | Job | Main step | Tests | Lane keys' self-test |
|---|---|---|---|---|
| I116, I117, I118 | 214, 232, 230 s | 187, 198, 189 s | 120 s, 186 CPU-s (I118) | 58 s alone, 27.8 CPU-s |
| I119 (a7b5f7dd) | 220 s | 185 s | 167 s, 309 CPU-s | 62 s beside, 46.4 CPU-s |

Counting the tests' own slowdown, the main step is 2 to 13 s shorter, within the runs' spread.
Both steps took more CPU beside each other than apart. The ruling was to drop I119 if CI
showed no gain, and it showed none.

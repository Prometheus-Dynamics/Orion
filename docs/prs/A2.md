## Build

- `comm/*` never depends on `node/*` and the reverse. `core/*` and `device/*` depend on nothing above them.
- No `rkyv` anywhere. No HTTP, QUIC or rustls dependency outside a crate the design names.
- `unsafe` only in the crates `AGENTS.md` allows.
- Rust files stay under 800 lines.
- Product names only in planning files.
- The gate already runs it when the script exists.

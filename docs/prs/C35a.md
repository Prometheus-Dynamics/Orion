# C35a: Every feature set builds, and the gate checks it

**Status:** done

**Group:** C. Comm and node logic

**Wave:** 18

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`crates/comm/comm-app`, `scripts/feature-matrix.sh`, `scripts/gate.sh`

## Build

The gate built the workspace with all features and nothing else. A use of something a feature
brings, written outside that feature's `cfg`, compiled there and failed for whoever took the
crate with fewer features.

## Built

- `orion-comm-app` builds with `default-features = false, features = ["nt4"]` again, and with
  every other single feature:
  - `last_good.rs` named `orion_check::Security`, a crate that is only there with `recovery`.
    It names `orion_config::Security`, the same type, which is always there.
  - `settings.rs` read the `shell` setting under `cfg(feature = "shell")` and used it outside
    one. The use has the same `cfg`.
  - `recovery` alone did not build: the recovery program tells systemd how the start went, and
    the feature did not bring `systemd`. It does now. A closure in `recovery_comm.rs` whose
    argument type was only fixed by a link feature says its type.
- `scripts/feature-matrix.sh` checks every workspace crate that has optional features with none
  of them, with each one alone, and with all of them: 98 builds today. With crate names as
  arguments it checks only those.
- The gate runs it as the step `feature matrix`, after the tests.

## Proved by

- Before the fixes the script failed on `orion-comm-app` for `nt4` alone (and every other
  feature set without `shell` and `recovery`) and for `recovery` alone. After them, 98 builds,
  0 failed.
- In the gate the step took 48 s. Run alone it took 1 min 45 s the first time and 14 s
  with nothing changed.

## Different from the brief

- Pairs of features are not checked, only none, each alone and all. `ssh` without `shell`,
  `recovery` alone and each `ssh-*` alone are among the single-feature builds, and they pass.
- The script uses `cargo metadata` and a short list, not `cargo-hack`, so CI needs nothing
  installed.

## Build

- Hello, Welcome, Reject, Ping, Pong, Refusal.
- Roles: client, provider, executor, node, peer, device. Session revision is `min(own, peer)`.
- Refusal carries a stable code so callers can branch on it.

## Proof

Vectors for each kind. A newer-revision peer and an older one both negotiate.

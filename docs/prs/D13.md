## Build

`OperatorEnroll` was on the wire and answered by the comm core, but no client call carried it,
and a person had no way from the command line to be let in to a board with security on.

1. **`Orion::enroll(public_key, name, enrollment_key) -> node::Enrollment`**: the node, its key
   and fingerprint, the cluster, the operator's state (`Enrolled`, `Pending`, `Revoked`) and what
   it may do. With the enrollment key, the proof (a MAC over the node's name and the operator's
   key) is made in the client; the key is not sent. `node::OperatorState` is re-exported.
2. **The proof moved to `orion-identity`** (`orion_identity::proof`), so a client makes it
   without the comm core's key store; `orion-keys` re-exports it as before.
3. **`orion operator ask --as NAME [--enrollment-key-file PATH]`** with the global
   `--key FILE` (the operator's key, made on first use; a network session is signed with it), and
   **`orion operator enroll KEY --as NAME`** for root on the board. The secret comes from a file,
   never the command line. The tool prints both keys, to compare and to pin.
4. **First-connection docs** in `docs/getting-started.md`: ask, be approved (root or the
   enrollment key), pin the board's key.
5. The test core takes `enrollment_key` in its `Options`.

## Built

As above. The operator's name is `--as`, since `--name` is the session's name for every verb.

## Proved by

- `crates/client/orion/tests/facade.rs`, `an_operator_asks_to_be_enrolled_and_proves_the_enrollment_key`:
  on a board with security on, a signed session asking for its own key is `Pending`, still
  `Pending` with a wrong enrollment key, `Enrolled` with the right one, with the node's key; and
  asking for another key is refused `denied`.
- `crates/client/ctl/tests/verbs.rs`, `operator_ask_with_and_without_the_enrollment_key`: the key
  file is made, `pending` exits 1, the key file's proof enrolls and exits 0, `ask` without `--key`
  and a key that is not one are not understood (2).
- `crates/comm/keys/tests/store.rs` (unchanged) checks the moved proof as before.

## Different from the brief

Root's `enroll` path is not run in the tests: they do not run as root.

`crates/core/supervise`

## Read on dev

- `docs/design/comm-core.md`

## Build

- Capped backoff (5 s for access paths, 10 s otherwise), never giving up.
- Rate-limited logs and restart counts.
- Component state reported through a small trait, so it can become a topic.
- Panic containment for a component task.
- Manual off, and auto-off only by configured policy. Access paths refuse that policy.

## Proof

Clock-driven tests for each rule.

## Built

- `README.md`: what Orion is, in four lines, and where to start.
- `docs/README.md`: the index, in three parts: using Orion, how it works, why it is this way.
- `docs/getting-started.md`: build `orion`, run both services as an ordinary user, the command
  line, a program, a workload with the sample executor, and where a board differs.
- `docs/settings.md`: every setting of both services in one place, with the file, the
  environment and unknown keys explained once. The tables in `docs/comm.md` and `docs/node.md`
  moved here; those pages link to it.
- `docs/operating.md`: running a board: systemd, getting in, what to watch, what happens when
  something dies, updating, what is kept. Each part links to the reference that has the detail
  instead of saying it again.
- `crates/client/orion/examples/first_program.rs`: the guide's program, built with the
  workspace.
- `scripts/check-links.sh`, a gate step: every relative link in the repository's Markdown goes
  to a file that exists, and every `#anchor` to a heading there.

## Proved by

- The link check passes on all 128 Markdown files, and fails on a missing file and on a
  missing heading (tried by adding both).
- Every command in `docs/getting-started.md` was run as written against a comm core and node
  logic started from the guide's settings: `node show`, `topic publish` and `topic read`, the
  example program (its output is the one in the guide), and `workload put` and `remove` with
  the sample executor.
- The example builds in the gate's clippy step (`--all-targets`).

## Different from the brief

- `docs/public-api.md` from dev is not carried over: the client's API is described in
  `docs/client.md` and in the crate's documentation.
- Writing the settings page found that the environment could not set a key with `_` in its
  name (`socket.node_uids`, `records.save_after_ms`, `ssh.max_connections`, ...): `_` in a
  variable was always read as `.`. `orion-config` now keeps keys with `.` and `_` as one, so
  `ORION_SOCKET_NODE_UIDS` is `socket.node_uids`. A test shows it.

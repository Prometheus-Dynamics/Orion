## Built

- `orion-link-can`: `CanCarrier`, a carrier of the one wire over a CAN bus, classic or FD, using
  the segmentation in `orion_wire::packet`. A bus has many devices; each address is its own
  session, the device `<bus>.<address>`, with its own reassembly. A device that stops talking
  loses its session and nothing else. A whole frame a session is not reading is dropped and
  counted, so one slow session cannot hold the bus.
- The bus is opened again every 250 ms after it fails, for as long as the program runs, and
  every session on it ends when it goes.
- Feature `socketcan`: `SocketCanBus`, the kernel's CAN sockets through the `socketcan` crate
  (a new dependency, because `unsafe` is not allowed in this crate). The socket receives only
  the bus's device identifiers.

## Proved by

`tests/bus.rs`, over a bus in memory, classic and FD: two devices as two sessions, a lost
segment, a foreign identifier, a silent device, an interface that is not there at start and one
that goes down under two sessions, and identifiers that cannot work.

`tests/vcan.rs` runs the kernel's sockets over `vcan0`. **Untested on the build machine**: the
`vcan` module is not loaded there and loading it needs root. The test prints `UNTESTED` and
passes when the interface is missing.

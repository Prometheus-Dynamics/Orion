## Build

- `[version][kind][seq][payload][crc]` with postcard bodies. `no_std`, no alloc.
- COBS for byte streams, segmentation for CAN, plain length-prefix on sockets.
- The whole kind table by range, as in the design, so later PRs cannot collide.
- Short bodies take defaults for missing trailing fields, longer bodies are accepted, unknown kinds are ignored.
- CRC-32C using hardware instructions where available.

## Proof

Frame round trips in every framing. 0 allocations per frame.

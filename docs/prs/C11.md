## Proof

Over a pty: 0 idle allocations and no busy polling.

## Built

- `orion-link-serial`: `StreamCarrier`, a carrier of the one wire over any byte stream (COBS
  frames from `orion_wire::stream`), and `Serial`, which opens a serial port in raw mode. The
  device on the link says hello like any client and is the principal `Device(<link name>)`.
  C12 and C13 can reuse the carrier with their own `Open`.
- The port is opened again 250 ms after it fails, for as long as the program runs, with the
  state reported through `orion_supervise::Report` so it can be an `orion.state.<link>` topic.
  The carrier hands the server a connection only once a whole valid frame has arrived, so a
  silent port is one task waiting on the descriptor.
- Feature `sealed`: dev's sealed channel (`sealed::channel`, ported with its tests) and
  `SealedListener`, a link whose bytes arrive over TCP from an operator's computer. The operator
  must be enrolled and granted the action `link.attach`. Handshakes run side by side, so a caller
  that says nothing holds nobody up; dev ran them one at a time.

## Proved by

`tests/pty.rs`, over a pseudo-terminal: on an open port with nothing arriving for 400 ms, 0
allocations, 0 reads and under 20 ms of processor time; the same on a connected session between
heartbeats; 0 allocations in 2,000 heartbeats and at most one read per frame. The port not being
there, the device being pulled out and another plugged in, and a device that stops talking are
all recovered from. `tests/sealed.rs`: 0 allocations in 2,000 sealed heartbeats; an operator
without the grant, an unknown key, a wrong board and junk are all refused.

## Different from the brief

- `unsafe` is not allowed in this crate, so the port is configured through `rustix` (a new
  dependency) and waited on through tokio's pipe ends, its safe way to wait on a descriptor that
  is not a socket.
- Dev's link gateway also held device actions, firmware transfer and status. Those are not a
  carrier's business here: they arrive as ordinary requests on the session (E and H).

## Changes

## Build

Cargo takes one crate at two revisions for two crates. A program that holds the device library
at one revision and Orion at another has two `shm_ring::Ring` types, and `Topics::adopt` does not
take the program's ring. Every repository that uses the `shm-*` family pins it at the same
revision; Orion moves its pins from b48efaf1 to 0aa30510, the revision the other consumers hold.

## Built

The eight `shm-*` workspace dependencies at `0aa305101109719a86d2958fe8554ec7f1c46ce6`. The
lockfile changes the revision only: the crates' versions are the same.

## Proved by

- `git diff b48efaf1 0aa30510 -- shm` in the device library is empty, and b48efaf1 is an
  ancestor of 0aa30510: the source Orion compiles is the same. What changed outside `shm/` is
  that repository's own build profile and `.cargo/config.toml`, which Cargo does not apply to a
  dependency. B9's numbers stand; it was not run again.
- The gate.

# B3: Doorbells

**Group:** B. Rings

**Wave:** 4

**Needs:** B1, A16

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

`crates/core/ring-doorbell`

## Read on dev

- `crates/transport-ipc/src/fd_latest/server.rs`

## Build

- A per-subscriber eventfd and a page only that subscriber writes.
- The publisher rings only a sleeping subscriber.
- The read side is pollable.

## Proof

No system call when the subscriber is awake. No lost wake-up in a stress test.

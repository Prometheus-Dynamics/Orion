## Fault

CI for I52 failed in node-app
`stops::a_program_that_never_says_ends_indeterminate_within_the_bound`: a run with a 200 ms
deadline and a 300 ms bound ended `Indeterminate` 499.7 ms after the test asked for it, before
the 500 ms it is owed.

Node logic's clock counts whole milliseconds, rounded down. A deadline was the reading when the
run came in plus its length, and it passed once a reading reached it. A reading of `n` is any time
in `[n, n+1)`, so a run that came in late in its millisecond had up to 1 ms less than its
deadline. The bound for the program's word, counted the same way from when it was told to stop,
had the same gap.

## Built

`stop::after(now_ms, ms)` is `now_ms + ms + 1`: a bound counts from the end of the millisecond it
was set in. The run's deadline and the program's bound both use it. Each is now never short, and
up to 1 ms long. A kept run's keep time is a time it is held at least, so it is unchanged.

## Proof

The action list's tests check each bound at its last millisecond: nothing at `due`, the stop or
the end at `due + 1`. With `after` counting as before (`now_ms + ms`) and the new tests, 4 tests
fail, 3 of 3 runs; with this change all 49 pass. node-app's `stops::` tests pass (4).

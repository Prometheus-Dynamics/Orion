# C23: A resource is said again only once its actions are back

**Status:** done

**Group:** C. Comm core

**Wave:** 18

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`crates/client/orion`, `crates/client/actions`, `docs/client.md`

## Build

On reconnect the client restored topics, then records, then actions. A resource record went out
again naming actions that were not registered yet: a client that found the resource and ran one
at once could be told there was no such action. Node logic already marks a provider's resource
lost when its session ends, so the gap was on the client's side only.

1. `Orion::reconnect` registers actions again before it puts records and asks for watches again.
2. A resource whose actions are refused on the way back is not said again.

## Built

- `Orion::reconnect`: topics, then actions, then records.
- `Actions` used up a registration's confirmation when it was waited for, and drops every
  confirmation from the broken session in `restore`. Before this, a confirmation was kept for
  ever: after a reconnect, whose request numbers can come round to the same ones, a refused
  registration was taken as accepted, and `reconnect` said everything was back when an action
  was not.
- `docs/client.md`: the order, and what a refused action does to the resource.

## Proved by

- `orion` facade test `a_resource_is_said_again_only_once_its_actions_are_back`. A provider's
  action name is taken by another program while the comm core is away. Its `reconnect` fails,
  and the store has no record of the resource. Not vacuous: with records restored before
  actions, the record is there. With confirmations kept from before, `reconnect` succeeds.
- The other facade tests, unchanged.

## Different from the plan

- The R2 list asked whether node logic keeps a resource record after its owner's
  session ends. It does not: `resources::gone` marks it lost. Nothing changed there.
- The stale confirmation was found by the test and fixed here, since without the fix the new
  order could not be seen to work.

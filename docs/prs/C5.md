# C5: Buffer topics in the broker

**Group:** C. Comm core

**Wave:** 7

**Needs:** C3, B8

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

`crates/comm/broker-buffers`

## Read on dev

- `crates/styx/src/ipc.rs` in Styx (`dev`)

## Build

- Takes a publisher's buffers once, hands them to each subscriber once.
- Forwards the subscribe request to the publisher without reading it.
- Handles a replaced pool.

## Proof

Late subscriber gets the current pool. Comm core restart does not interrupt frames.

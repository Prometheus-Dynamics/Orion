# B2: Ring concurrency proof

**Status:** done

**Group:** B. Rings

**Wave:** 4

**Needs:** B1

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Creates

`crates/testing/ring-model`

## Build

- `loom` model of writer against readers, including overwrite during read.
- Fuzz the reader against arbitrary ring contents.

The model found one flaw in B1, fixed here: a lane read accepted a slot holding a newer sample, so
`latest` could go backwards. Slots now carry their lane sequence (`docs/ring.md`). The models are
bounded (2 to 3 preemptions, 2 to 4 publishes), which is what `loom` can finish; "all
interleavings" means all within those bounds.

## Proof

All interleavings pass. Fuzzing finds no out-of-bounds read.

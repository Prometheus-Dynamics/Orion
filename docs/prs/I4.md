## Build

- systemd units for comm and node, and nothing specific to one image build system. How Orion is
  built and installed into an image is described by whoever owns the image's build config,
  from `packaging/README.md`.
- No systemd start limits, which would be an auto-off.

## Proof

Units pass `systemd-analyze verify`.

## Built

- `packaging/systemd/orion-comm.service`: `orion comm` as root with group `orion`.
  `Type=notify` with `WatchdogSec=30s`; `Restart=always` with a backoff from 1 s to 30 s over
  five tries and `StartLimitIntervalSec=0`. `RuntimeDirectory=orion` (0750, kept across a
  restart), `StateDirectory=orion`. Hardened only as far as SSH logins allow: nothing that would
  follow a login into its shell.
- `packaging/systemd/orion-node.service`: `orion node` as the `orion` user, wanting and after
  the comm core but not bound to it, its state in `/var/lib/orion/node`. Fully hardened.
- `packaging/systemd/orion.conf.example` (`/etc/orion/orion.conf`), with
  `socket.node_uids = 901`; `orion.sysusers` (uid and gid 901, in `dialout`); `orion.preset`.
- `packaging/README.md`: each file and where it installs, what each unit does and why, the
  user, and how to build the binaries for a board.
- `scripts/packaging-check.sh`, a gate step: `systemd-analyze verify` of both units,
  `systemd-analyze security` of node logic's unit (at most 2.5), `systemd-sysusers --dry-run`
  of the user. Each is skipped with a line where the tool is missing.

## Proved by

- `scripts/packaging-check.sh`: both units load with no message; a unit with a bad value
  makes it fail. Node logic's unit scores 1.8.
- On a CM5 (testing/board-runs/I4.md): the comm core is reported started when it is serving;
  node logic runs as uid 901 and is let in; after `kill -9` the comm core is back and node logic
  answers again within 200 ms without restarting; a stopped comm core is killed and restarted
  by the watchdog at 30 s.

## Different from the brief

- No image build system files. The brief first asked for build fragments for each form; they
  were taken out: an image's build config, kept by whoever owns the image, says how Orion is
  built and installed, written from `packaging/README.md`. The proof is the units' alone.
- The comm core's unit is not scored by `systemd-analyze security`: it lets logins in as the
  users they name, and most of what the score counts would follow every login.

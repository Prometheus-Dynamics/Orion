# I127: measure-change.sh measures a batch of files

**Status:** done

**Group:** I. Finish

**Wave:** 19

**Needs:** I126

Read `AGENTS.md` and `docs/design.md` first.

## Why

A batch touches several files at once, and some of them are not Rust: the keys self-test lives
in `scripts/lane-reuse.py`. `scripts/measure-change.sh` took one file, and its comment was `//`,
which is a syntax error in Python. A batch's gate cost could not be measured.

## Changes

- **`FILE[,FILE...]`:** several files, comma-separated, are one change. Each is saved before the
  first run and put back after each run, with a fresh mtime as before.
- **The comment fits the file:** `#` in `.py`, `.sh` and `.toml`, `<!-- -->` in `.html`, and `//`
  in any other.
- **Each kind checks every file before any run:**
  - a file that does not exist is refused;
  - `unused-fn` needs every file to be `.rs`;
  - `used=TEXT` needs TEXT in every file.

## Proved by

In a scratch repository, with a stub `run-gate.sh` that records each run's diff:

- the comment kind on `scripts/lane-reuse.py` and `video.rs` added `# measure-change …` and
  `// measure-change …`, different in each run;
- the Python still compiled after the change;
- both files were back as committed after the runs;
- `unused-fn` on a `.py` file, `used=TEXT` missing from one file, and a missing file were each
  refused with exit 2 before any run.

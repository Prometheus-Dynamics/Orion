**Status:** done

**Group:** F. Leaving the board

**Wave:** 10

**Needs:** F7, F3

**Runs:** cloud

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`crates/gateways/nt4`, `crates/gateways/nt4-gateway`, `crates/comm/comm-app`

## Build

- `nt4.listen = ws`: the NT4 gateway takes its clients from the WebSocket listener
  (`ws.listen`) instead of a port of its own, by the subprotocol they ask for.

## Proof

An NT4 client that connects to the WebSocket port sees the mapped topics.

## Built

- `orion-nt4`: `ServerConfig.listen` (on by default). A server that does not listen has
  no port and takes its connections only from `Server::taker()`, a `Taker` that can be
  moved to another task and hands it WebSocket connections that are already open.
- `orion-nt4-gateway`: `Nt4Listen`, either an address or `ws`; `nt4.listen` is parsed into
  it. `Gateway::taker()` and `Gateway::take()`. The two NT4 subprotocol names are exported.
- `orion-comm-app`: with `nt4.listen = ws`, the WebSocket listener hands the connections
  that ask for `v4.1.networktables.first.wpi.edu` or `networktables.first.wpi.edu` to the
  gateway (`src/nt4_ws.rs`); the rest stay Orion's. `nt4.listen = ws` without `ws.listen`
  refuses to start. `CommCore::ws_addr()` says where the WebSocket listener is.

## Proved by

- `cargo test -p orion-nt4-gateway`: with `ws.listen = 127.0.0.1:0` and `nt4.listen = ws`,
  the NT4 client of `orion-nt4` connects to the WebSocket port and sees `/Tank/level`
  follow the board's topic. With the forwarding task left out, the same test fails. A comm
  core with `nt4.listen = ws` and no `ws.listen` does not start, and says why.

## Different from the brief

- No brief was written before this PR; F7 left the sharing unwired and this wires it.
- The gate turned up a race in `orion-ssh-sandbox`'s test, fixed here: it read a child's
  `NoNewPrivs` before the child had set it on itself, and could count a child left over
  from the connection before. It now waits for the earlier children to go, then for a
  child that has the flag set.

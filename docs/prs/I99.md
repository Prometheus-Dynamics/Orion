## Why

Two things, both tests.

1. **Whether anyone listens.** A program that reads a device to publish it, four times a
   second, reads it for nobody when nobody is connected. A publisher has
   `publisher.subscribers()` and is sent a message when the count changes, but nothing showed
   the count moving for a listener that is not on the board. A program is about to build on
   it.
2. **A test that passed where it could not run.** I98's sandbox test said so and passed where
   `bwrap` could not load its filter. In CI that could be every run.

## Built

- **`watched::a_publisher_is_told_when_a_subscriber_on_the_network_comes_and_when_it_goes`**
  (`orion-test-board`, a real board): the count is 0; a listener over the network makes it 1;
  the publisher publishes and the listener has the value; a second listener on the board
  makes it 2; each going is told, down to 0.
- **`a_publisher_is_told_when_the_only_listener_is_on_another_node_and_when_it_goes`**
  (`orion-topic-peers`, two comm cores): 0, then 1 while a program on the other node
  subscribes, then 0. A test there already showed two programs on the other node count as
  one, the link, and that the count drops when the last goes.
- **No product change:** both pass as the code is. With the count a topic reports set to always zero, each fails 3 of
  3 runs.
- **The sandbox test** fails under the gate where it cannot run, as the namespace tests do
  (`NAMESPACE_TESTS=required`). Elsewhere it prints that it was skipped.
- **CI** installs `bwrap` where the runner lacks it.

## What a publisher can rely on

- The count includes a listener on the network and one on another node. Another node counts
  as one listener however many programs there subscribe.
- A topic declared `OnSubscribe::Latest` gives a late listener the newest sample at once. A
  publisher that stopped reading while nobody listened should read at once when the count
  leaves zero; until it publishes, that newest sample is from before it stopped. An
  `expiry_ms` on the topic keeps a value that old from being handed out.

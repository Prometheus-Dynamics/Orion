## Build

- `Checked<T>`, with a private constructor. `Principal`, `Policy`, `Request`.
- `Check::decide(principal, request, policy) -> Result<Checked<T>, Refused>`.
- One switch for security. Off costs nothing.
- `trybuild` tests prove a handler cannot be called without a `Checked<T>` and an action cannot be registered without a policy.

## Proof

Compile-fail tests pass. With security off the check compiles to no work.

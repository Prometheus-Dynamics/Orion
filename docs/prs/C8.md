## Build

- Board identity, served to anyone who connects and signed over the network.
- Other programs add fields as topics. Orion does not invent board facts.

Two kinds were added at the end of the session range, `IDENTIFY` and `IDENTITY` (new kinds, so no
recorded vector changed). A policy can now say an operator needs no grant (`without_grant`), for
the few things that are how one becomes known at all: this, and asking to be enrolled, which no
longer needs a special case in the trust store.

Not carried from dev: the HTTP endpoint (`/.well-known/pd-device` on port 5899). The document is
asked for over any Orion connection instead; tools that looked for the HTTP one catch up. The SSH
host-key fingerprints dev put in the document are board facts like any other now: whoever serves
SSH publishes them as `hello.` topics, which will be Orion itself once G1 lands.

## Build

- Bool, integers, floats, strings, bytes, arrays, structured values with a pinned type name.
- A fixed layout for numbers, so reads need no decoding.
- Encode and decode with no allocation for fixed-size types.

## Proof

A structured pose round trips with 0 allocations.

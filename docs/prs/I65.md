# I65: The PR list reads every brief again, and the gate keeps it so

**Status:** done

**Group:** I. Finish

**Wave:** 19

**Needs:** I64

Read `AGENTS.md` and `docs/design.md` first.

## Changes

`scripts/pr-status.py`, `scripts/gate.sh` (one step), `docs/lock.md`, `TODO.md`.

## Fault

`AGENTS.md` sends whoever picks up a PR to `python3 scripts/pr-status.py`. It had not run for a
long time:

- **It crashed** (`AttributeError`) on the first brief with no `**Needs:**` line. 39 briefs have
  none, and 17 more write their header as a list (`- **Status:** done`), which it did not read.
- **Its sort and its branch names took only `A`–`I` with a number.** `C35a`, `I55b` and the
  `J` group would have failed or been missed.
- **It knew `done` and nothing else,** so a dropped PR (I2) was listed as still to do.
- **Nothing ran it,** so none of this was seen.

## Built

- **Both header forms are read.** No `Needs:` line, `nothing` or `none` mean the PR needs
  nothing. A need written in words, such as another library's pin (C64), is outside Orion: it is
  not waited for in this list.
- **Ids are a letter, a number and an optional letter**, sorted in that order. Branches are
  `pr/<id>` in the same form.
- **A dropped PR is listed as dropped,** not as ready or blocked.
- **`--offline` reads the briefs alone** and exits 1, saying which briefs and why, for any of:
  - a file name that is not an id;
  - a brief with no status;
  - a need naming an id that has no brief.
- **The gate runs `pr-status.py --offline`** as a step (`pr list`, `1:1`), among the checks that
  build nothing.

## Proof

- **Today:** 238 merged, none open or blocked, I2 dropped, and H8 ready (waiting on its board).
  Online, through `gh`, the same.
- **The old script** fails on the same briefs: `AttributeError: 'NoneType' object has no
  attribute 'group'`.
- **`--offline` exits 1** for a brief with no status, a need `C3O` with no brief, and a file
  `notes.md`, and 0 for the briefs as they are.
- **The landing gate passed.**

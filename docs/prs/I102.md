## Why

The device library's `next` is at `214c0ca7`, and a consumer's pin waits on Orion holding the
same rev. Cargo builds one crate twice when it is taken at two revs, so every consumer pins the
`shm-*` family at one. This is its own change, so that this Orion rev and that device-library
rev are the pair every consumer takes.

- **The lockfiles.** Only the `source` lines change: 7 in the workspace's, 1 in each

- **No source Orion builds changes.** Nothing under the device library's `shm` directory

  both. The 56 files that changed belong to its services, drivers, backends, packaging, tests

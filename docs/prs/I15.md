## Changes

## Build

A fresh worktree's first gate built everything, in every lane: the dependencies, at each
profile and target, as well as the workspace. Target directories are never shared between
worktrees, so nothing was reused.

## Built

- **`scripts/seed-target.sh FROM TO`.** It copies FROM, another worktree's target directory, to
  TO with `cp -a --reflink=auto`.
  - On a filesystem that clones files (btrfs here), the copy takes seconds and no space until a
    file changes on either side. Elsewhere it says first how much it will copy whole.
  - It refuses a TO that is not empty, and replaces an empty one rather than copying into it.
  - A copy, never a share: each worktree keeps its own target directory, and cargo's
    fingerprints decide what is rebuilt. The workspace's own crates sit at other paths in the
    new worktree, so they are rebuilt. The dependencies are not.

## Proved by

A worktree made at this commit's parent, gated whole with an empty target directory, then
again with one seeded from `orion-next`'s. Two rounds, at load 47–65 (s):

| Round | Cold, wall | Cold, CPU (user) | Seeded: copy + gate, wall | Seeded, CPU (user) |
| --- | --- | --- | --- | --- |
| 1 | 589 | 6,689 | 25 + 178 | 1,932 |
| 2 | 516 | 5,731 | 30 + 226 | 2,098 |

Both gates passed in each round. The script refused a non-empty TO (exit 1), and seeded an
empty one in 60 s, as a copy in place, not nested inside it.

## Build

- A program that cannot write shared memory sends samples, and the comm core writes the ring.
- Subscriber counts become demand events too.

This is the publishing direction only. Sending samples out to a subscriber that cannot map shared
memory is F2 (outbound limits and the drop rule): the broker already counts such a subscriber and
marks it, and nothing reads the ring for it yet.

## Proof

A remote-style publisher and a shared-memory reader agree. 0 allocations per sample.

# F8: The NT4 gateway's client form against a SystemCore

Run on the test board (an aarch64 Cortex-A76 module, image dev.993) joined to a SystemCore over its USB network. The
SystemCore runs the NT4 server of its robot program (WPILib 2027.0.0-alpha-8) on port 5810.
`next` is at F7 (b9c8c27) plus this PR.

## How it was run

`nt4-client-gateway-demo` (an example of `orion-nt4-client-gateway`: a comm core with the
gateway, a program publishing `tank.level`, a program reading `robot.state`) and `nt4-dump`
(an example of `orion-nt4`: an NT4 client that prints what it is sent), built for
`aarch64-unknown-linux-musl` in release, run from `/tmp` on the board with the board lock
held:

    nt4-client-gateway-demo board 172.31.209.221:5810 /OrionF8/level string@/Robot/WPILibVersion
    nt4-dump --host 172.31.209.221 --prefix /OrionF8/ --name orion-f8-watch

The mapping the demo was given:

    nt4.server  = 172.31.209.221:5810
    nt4.publish = tank.level:litres=double@/OrionF8/level
    nt4.accept  = robot.state:value=string@/Robot/WPILibVersion

The gateway ran for seven seconds; the second client watched for the last four and for two
seconds after the gateway was stopped. Nothing on the board or the SystemCore was changed:
the binaries ran from `/tmp` and were removed, and the one topic the gateway published on the
server went when it left.

## What happened

| Check | Result |
| --- | --- |
| The board joins the server | Joined at once: `joined the server` |
| A topic of the server's is published on the board | `robot.state` read `2027.0.0-alpha-8`, which is `/Robot/WPILibVersion` |
| A field of the board's is a topic on the server, with the mapped name and type | The second client was sent `announce /OrionF8/level [double]` |
| Its values follow the board's | 41 values in four seconds, each 2.5 litres above the one before (the tank goes up 0.5 every 20 ms and the server sends a client one value every 100 ms) |
| The gateway leaves nothing behind | `unannounce /OrionF8/level` when it was stopped |

The clock estimate against the server settled with a round trip of 143 µs.

The NT4 client itself was also pointed at the SystemCore from a PC on its network and was
sent the server's whole table: 40 topics of the types string, int, boolean, double,
`double[]`, `struct:ControlWord`, `structschema` and `msgpack`.

## Not measured

What the gateway costs the board. The demo's process was at 0% CPU in `top` while it ran;
that is one look, not a measurement.
